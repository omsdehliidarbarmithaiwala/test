# Om's Dehlii Darbar Mithaiwala — Counter POS Billing Terminal

Official, standalone Counter POS Billing Terminal for **Om's Dehlii Darbar Mithaiwala (Since 1947)**.

## 🌟 Key Features
- **Gram-Accurate Weighing**: Calculates exact sweet prices using counter rates: `(Rate / 1000) * grams`.
- **Mobile Optimized**: Full touch interface with mobile tab switching and sticky floating cart bar for phone and tablet use at the counter.
- **1-Tap WhatsApp Dispatch**: Instant digital invoice generation and dispatch directly to customer mobile numbers (`wa.me/91<Phone>`).
- **1-Tap SMS Dispatch**: Instant text message fallback.
- **Thermal Receipt Printing**: `@media print` support for standard 80mm ESC/POS counter thermal printers.
- **Support for Pieces, Boxes & Custom Items**: Sell sweets by exact grams, piece count, pooja boxes, or on-the-fly custom items.
